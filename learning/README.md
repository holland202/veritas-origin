# Learning

Short, optional lessons written while this repository is built. They explain ideas; **they are not evidence.**
Nothing in `learning/` supports, replaces or changes any result in `experiments/`, `evidence/` or `reports/`.

Each lesson has three depths. Stop at whichever is enough:
- **Understand:** the idea in plain English.
- **Build:** the real commands, files and vocabulary.
- **Challenge:** something to try yourself that could prove the lesson wrong.
